# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly
by opening a [private security advisory](https://github.com/SebTardif/MiniBuildRust/security/advisories/new)
on this repository.

Please include:

- A description of the vulnerability
- Steps to reproduce or a proof of concept
- The impact you believe it has

You will receive a response within 7 days. Please do not open public
issues for security vulnerabilities.

## Supported Versions

Only the latest release is supported with security updates.
